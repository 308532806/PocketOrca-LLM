# PocketOrca-LLM v1.4.1 fix11 — 推荐参数更准了

基于官方 **v1.4.1**，fix9 的全部内容与 fix10 的能力自动检测完整保留。本次把"推荐参数"从"只看手机"升级为"看手机 + 看模型"。

**签名与历史版本一致，可直接覆盖安装。**

## 新功能：模型感知的推荐参数（纯 Web 层，零运行时开销）

1. **模型感知（按文件大小调上下文档位）**：推荐不再只看 SoC 和内存。模型文件超过内存 6 成（如 8GB 手机装 5GB+ 模型）自动降一档上下文防 OOM；小模型（不足内存 3 成）自动升一档，把内存吃满。调整原因会写在推荐卡备注里。BigMoE 模型无文件大小信息，走原模板。
2. **内存扩展手动开关**：推荐卡新增"内存扩展"开关。开了内存扩展（闪存虚拟内存）的手机，上下文推荐放宽一档（上限 32768）——扩展内存能防 OOM 但速度远不如物理内存，备注里会写清楚这笔账。开关状态持久保存。为什么手动？App 拿不到 swap 状态，自动检测需要 root/改 Java，做不到，只能手动。
3. **换模型自动刷新**：切换模型后推荐卡立即按新模型重算，不用重启 App。

## 性能说明

- 推荐计算只在启动、换模型、拨开关时跑一次（查表 + 一次除法），无轮询、无后台任务，不增加设备负担，符合"手机性能用在跑模型上"的原则。
