# PocketOrca-LLM v1.4.0 fix4 — GPU(OpenCL) 旧驱动全面兼容 + NPU 修复 + 三引擎测速

本包基于官方 **v1.4.0 release APK**（sha256 `14885aad…e5478`）以"手术式"修改制作，**未改动 dex 与推理逻辑**。

fix4 = fix3 + **GPU 运行期兼容修复**（真机验证：骁龙 765G / Adreno 620 / Android 12 上 GPU 引擎从"闪退"到**完整可用**）。已在本机（SM7250 真机）用 `pm install` 安装并以独立进程 + App 内实测验证通过后发布。

> 安装：官方版需先卸载；fix1 / fix2 / fix3 用户可直接覆盖安装（同一签名）。

## 1. GPU(OpenCL) 引擎修复（fix2→fix4 三个阶段，缺一不可）

**阶段一（fix2）符号加载**：`libggml-opencl.so` 因 `BIND_NOW` 加载期强依赖 OpenCL 3.0 符号 `clCreateBufferWithProperties`，旧驱动不导出 → `dlopen` 失败。
→ dynstr 改名 `clCreateBuffer` + 调用点 `nop`（该调用属默认关闭的 X2 大型缓冲实验路径）。

**阶段二（fix3）符号加载（续）**：同一模式，`clGetKernelSubGroupInfo`（CL 2.1）缺失。
→ 两个调用点直接返回"查询失败"（走 llama.cpp 既有降级：禁用 mamba2 专用 subgroup kernel）+ dynstr 占位改名。

**阶段三（fix4，本版）运行期**：kernel 集里的 `flash_attn_repack`（为 wmm prefill 准备 4 个 kernel）在旧驱动上**编译失败**（驱动缺 `cl_khr_3d_image_writes` 扩展），而构建调用为 `fatal=true` → **`exit(1)`**；因 GPU 引擎在 App 进程内运行（JNI），**整个 App 闪退**（真机 ExitInfo 实证 `reason=EXIT_SELF`）。
→ `@0x3405F4` fatal 参数 `1→0`（编译失败返回 nullptr 不再退出）+ 4 处 CL_CHECK 失败跳转 `cbnz→nop`（4 个句柄保持 NULL）。
**安全性论证**：wmm prefill 路径在本包中**不可达**——其门控 `use_fa_bin_kernels_prefill()` 首先检查 Adreno bin 内核库加载的 kernel 是否为 NULL，而该 bin 库（`libadreno-opencl-kernels.so`）不随本包分发（宏未编译），故恒为 false；4 个 NULL 句柄无任何调用路径。

**真机验证结果**（SM7250 / Adreno 620，驱动 OpenCL 2.0 build 2022）：
```
load_tensors: offloaded 43/43 layers to GPU
llama_context: constructing llama_context
ggml_opencl: OpenCL device: QUALCOMM Adreno(TM)
...
llama_server: model loaded
llama_server: listening on http://127.0.0.1:XXXX
```
推理请求（/completion）正常返回结果；`-fa on` 与 `-fa off` 均通过。

## 2. NPU(HTP) 启动崩溃修复（自 fix1）

v1.4.0 在 HTP arch > 79 机型（骁龙 8 Elite Gen 5 等）上 NPU 模式崩溃（`fastrpc_mmap failed` / exit 134）：新 DMA64 扩展映射与内置旧 `libcdsprpc.so` 不兼容。修复 = 强制 `opt_dma64 = 0`（`libggml-hexagon.so` 两处字节补丁）。修复后 so sha256 `27713036…c06b9bec` 与社区独立修复一致。

## 3. 状态胶囊开关修复（自 fix3）

右上角状态胶囊的开关滑块此前永远不动（原版 `setState` 未同步 `#statusPill` 的 `running/starting` 样式类）。现已修复。

## 4. 三引擎测速（自 fix1）

Server 页「引擎测速」：用当前模型依次实测 NPU / GPU / CPU（生成速度 t/s、提示处理 t/s、加载耗时，标出最快），完成后自动恢复原引擎。

> 注：无可用 NPU 的机型（如本验证机 765G）测速里 NPU 会显示"启动失败"——正确结果。
