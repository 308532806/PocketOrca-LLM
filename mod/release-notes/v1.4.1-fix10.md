# PocketOrca-LLM v1.4.1 fix10 — 能力自动检测与门控

基于官方 **v1.4.1**，fix9 的全部内容完整保留。本次新增**能力自动检测**：不可用的引擎/模式自动屏蔽，不再浪费一次启动的时间开销。

**签名与历史版本一致，可直接覆盖安装。**

## 新功能：能力门控（纯 Web 层，零运行时开销）

1. **设备能力（SoC 查表，零开销）**：从设备信息识别 SoC，只有骁龙 8 Gen 2 / 8 Gen 3 / 8 Elite / 8 Elite Gen 5（HTP v73+）才视为有可用 NPU。无 NPU 的机型（如 765G、天玑等）自动置灰 **NPU** 与 **MTP** 按钮，点击会 toast 告知原因，不再尝试启动。
2. **模型能力（探测一次，终身记忆）**：MTP 需要模型含 MTP 层。首次对某模型使用 MTP 即探测一次，结果按模型路径缓存；之后该模型再选 MTP 会直接显示"当前模型不含 MTP 层，已自动屏蔽"，不再重复浪费 ~20 秒加载时间。测速中已知不支持的引擎直接跳过并标注原因，不启动。
3. **三处拦截**：引擎切换按钮（setProfile 守卫，附原因 toast）、启动入口（doStart 防御）、测速队列（benchNext 预跳过）。启动时若恢复的引擎不可用，静默回退到 CPU/NPU 可用项。
4. 测速 chips 同步置灰并自动取消勾选；换模型后重新评估。

## 性能说明

- 能力判断全是内存查表 + localStorage 读取（仅在启动/换模型/探测后触发），无轮询、无后台任务，不增加设备负担；省下的是一次次无效的模型加载时间，手机性能更多用在实际推理上。
