# PocketOrca-LLM v1.4.0 fix6 — 测速修复 + 推荐参数 + 全部既有修复

fix6 = fix5 全部内容 + 测速"无 timings 数据"修复 + 设备推荐参数 + HTML 结构修复。

> 安装：官方版需先卸载；fix1~fix5 用户可直接覆盖安装（同一签名）。

## 1. 测速"无 timings 数据"修复（fix6 新增）

fix5 的测速功能请求的是 `/completion`（llama.cpp 原生端点），但服务器运行在 OpenAI 兼容模式，timings 只打在日志里而不在 HTTP 响应中，导致每次测速都报"无 timings 数据"。

**修复**：改用 `/v1/chat/completions`，从 `usage.completion_tokens` + 实测耗时估算生成速度（t/s），从 `usage.prompt_tokens` 估算提示处理速度。

## 2. 设备推荐参数（fix6 新增）

「服务」页新增「推荐参数」卡片：根据本机 SoC / 内存自动匹配最优参数模板，一键应用。

| 设备 | 引擎 | 上下文 | ubatch | 线程 | KV 卸载 |
|---|---|---|---|---|---|
| 骁龙 8 Elite / 8 Gen 3 | NPU | 8K | 1024 | 8 | 开 |
| 骁龙 8 Gen 2 | NPU | 4K | 512 | 6 | 关 |
| 骁龙 7+ Gen 3 | CPU | 4K | 256 | 6 | 关 |
| 骁龙 765G | CPU | 4K | 256 | 4 | 关 |
| 未识别（按内存） | CPU | 2K~8K | 128~512 | 4~6 | 视情况 |

未识别的设备按内存分级兜底推荐。推荐参数仅供参考，可随时手动调整。

## 3. HTML 结构修复（fix6）

修复 fix5 中状态胶囊精简时误删的一个 `</div>` 闭合标签（导致页面 DOM 不平衡，WebView 可能渲染异常）。

## 4. 自选测速 + UI 精简 + 性能优化（自 fix5）

- 三引擎测速支持 NPU/GPU/CPU 自选勾选，选择被记住
- 状态胶囊移除指示灯/外框/底色，文字与开关基线对齐
- 日志轮询仅在日志页可见时运行；checkPort / cliRefreshState / bmoeDlStatus 均降频+守卫
- 深色主题对比度提升至 WCAG AA（7.4:1）
- 引擎切换加 loading 态；测速表格淡入过渡

## 5. NPU / GPU 兼容修复（自 fix1~fix4）

- `libggml-hexagon.so` 2 处字节补丁：关闭 DMA64 扩展映射，修复 HTP arch>79 机型 NPU 启动崩溃
- `libggml-opencl.so` 10 处字节补丁：CL 3.0/2.1 符号兼容 + wmm-repack 编译降级，修复旧 Adreno 驱动 GPU 闪退

## 已知限制

- 低内存/老 GPU 机型禁止 App 内 GPU 完整测速（曾致系统重启）
- 部分机型无可用 NPU（骁龙 7 系旧平台），测速显示失败属正常
- 推荐参数基于社区实测数据，实际效果因机型/系统/模型而异
