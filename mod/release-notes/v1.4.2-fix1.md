# PocketOrca-LLM v1.4.2 fix1 — 基座升级到官方 v1.4.2

基于官方 **v1.4.2**（2026-10-08），此前的全部改动（fix9～fix13）完整 rebase。

**签名与历史版本一致，可直接覆盖安装。**

## 上游 v1.4.2 新能力（本次一并获得）

1. **多模态输入**：Chat 页 📎 按钮可发图片（配 Qwen3-VL 等视觉模型，mmproj 放模型同目录自动加载，支持 JPEG/PNG）与语音备忘录（配 Qwen3-ASR-0.6B 录音转文字），NPU/GPU/MTP 引擎可用
2. **会话持久化**：聊天历史自动保存，重启 App 后恢复；📎 菜单可保存/恢复/删除会话（KV 缓存直接恢复，无需重新 prefill）
3. **llama.cpp 基线升级**：Q2/Q3_K 量化可跑 NPU（9B 模型换 Q3_K_M 省约 1.3GB 内存），MTP 投机解码进官方基线
4. **8 Elite Gen 5 NPU 启动崩溃修复**：官方默认规避 DMA64 映射与旧 DSP 固件的不兼容（红米 K90 Pro Max 等新机型直接受益）

## 本次合并的技术说明

- **.so 字节补丁退役**：v1.4.1 时代的 hexagon DMA64 补丁与 OpenCL 兼容补丁不再需要——
  上游 v1.4.2 已自行修复 DMA64 映射问题，且新版 `libggml-opencl.so` 不再强依赖
  `clCreateBufferWithProperties` / `clGetKernelSubGroupInfo`（旧补丁的根因消失）。
  本次为纯 Web assets 手术，未动任何 .so。
- **Web 层三路合并**：上游 v1.4.2 的多模态/会话 Web 代码已完整移植（附件栏、录音、
  会话槽位、历史持久化），与我们的 markdown、清空按钮、测速、推荐、门控等改动共存。
- 若 765G 等老机型的 GPU 引擎出现异常，请反馈，将单独处理。
