# PocketOrca-LLM v1.4.1 fix12 — UI/交互系统优化

基于官方 **v1.4.1**，fix9～fix11 的全部内容完整保留。本次是第一次**系统性 UI/交互优化**：只动 Web 层，全部零运行时开销（纯 CSS、一次性 DOM、事件委托）。

**签名与历史版本一致，可直接覆盖安装。**

## Chat 页（变化最大）

1. **Markdown 渲染**：代码块（含语言标签 + 一键复制）、行内代码、加粗/斜体、列表、引用、标题、分割线。关键设计：**只在消息完成时渲染一次**，流式阶段保持纯文本 textContent，手机性能全部留给推理，零额外负担。
2. **清空/新对话**：输入行新增「清空」按钮，复用现有确认框，清空后显示空状态。生成中点清空会被拦下。

## 服务页

3. **主按钮上移**：「启动服务」从 4 张卡片底部移到**模型卡正下方**——最高频操作，不再滚过测速/推荐/参数三张卡。
4. **检测更新不再是桩**：真查 GitHub Releases API，比对当前版本；有新版/已最新/网络失败都有明确提示（以前永远显示"已是最新"）。

## 测速

5. **默认勾选收敛**：无历史选择时默认只勾 NPU+CPU（原来全选）。GPU/MTP 手动加——默认比警告更安全，也配合"低内存设备禁 GPU 完整测速"红线。
6. **结果可读性**："pp" 改为中文"提示处理"；测速中显示总进度 `2/4`；失败行给「查看日志」跳转。

## 细节

7. **错误提示可操作**：「服务未运行」toast 带「去启动」按钮，一点跳转服务页；CLI 页 offline 提示整块可点跳转。
8. **Toast 分级**：成功/警告/错误三色边框，显示时长按文案长度动态（1.6～4.2 秒）。
9. **对比度**：卡片标题从 `--faint` 换 `--dim`（2.89 → 7.43，纯 CSS）。
10. **触控目标**：分段按钮 34px → 44px，chips 26px → 40px（纯 CSS）。
11. 「使用说明详见 Github 发布页」改为可点击链接。
