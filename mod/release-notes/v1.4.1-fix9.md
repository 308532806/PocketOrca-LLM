# PocketOrca-LLM v1.4.1 fix9 — MTP 测速提示 / 键盘遮挡 / 生成时滚动

基于官方 **v1.4.1**，fix8 的全部内容完整保留，本次为纯 Web 层（assets）修复三连。

**签名与 fix1~fix8 一致，可直接覆盖安装。**

## 修复内容

1. **MTP 测速失败提示更明确**：普通 GGUF（不含 MTP 层）测 MTP 时，之前只显示笼统的"✗ 启动失败"。现在会读取日志中的 `doesn't contain MTP layers` 特征，显示为"✗ 需 MTP 权重（当前模型不含 MTP 层）"；测速卡片也新增一行提示"MTP 引擎需要 MTP 权重模型"。小米 15（骁龙 8 Elite，HTP v79）等 MTP 机型换上 MTP 权重即可正常测速。

2. **Chat 页键盘遮挡输入框**：viewport 增加 `interactive-widget=resizes-content`，键盘弹起时布局视口自动收缩；另加 `visualViewport` 兜底（旧 WebView / adjustPan 下手动压缩 body 高度并把输入行滚入可见区）。

3. **生成时不再强制滚到底部**：之前每个 token 都 `scrollTop = scrollHeight`，生成中无法上滑看历史。现在改为"跟随模式"——只有停留在底部时才自动跟随；上滑后右下角出现"↓ 回到底部"悬浮按钮，点一下回到跟随。日志页同款交互逻辑。
