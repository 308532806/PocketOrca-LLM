# PocketOrca-LLM v1.4.1 fix8 — 基于上游 v1.4.1 的全量移植

本包基于官方 **v1.4.1 release APK**（45.1MB，比 1.4.0 小 2.5MB）以"手术式"修改制作。

**⚠ 重要：本包基于 v1.4.1，与 fix1~fix7（基于 v1.4.0）签名一致可直接覆盖安装；官方 v1.4.0 用户也可直接升级。**

## 上游 v1.4.1 新功能（本包完整保留）

1. **MTP 引擎**（Qwen3.5 NPU 多 token 预测）：`--spec-type draft-mtp`，兼容机型上 NPU 生成速度可翻倍。引擎选择新增 **MTP** 按钮
2. **深度思考按钮**：Chat 页新增"思考"开关（enable_thinking 参数化）+ "结束思考"按钮（reasoningEnd）
3. **空闲自动卸载**：参数页新增 3/10/30 分钟档，空闲后释放模型内存，下次请求自动重载（省内存利器）
4. **KV cache 量化 q8_0**：所有引擎默认 `-ctk/-ctv q8_0`，**KV 内存省约一半**——大上下文不再爆内存
5. **体积精简**：删除 8 个非 server 的 `-impl.so`（-13.5MB）

## 本 fork 全部修复（fix1~fix7 移植到 1.4.1 基底）

### 功能修复（JS 层，19 项修改全部重放）

- **自选测速（含 MTP）**：NPU/GPU/CPU/**MTP** 四引擎勾选，localStorage 记忆；走 `/v1/chat/completions` 从 usage 估算 t/s
- **切页状态误显修复**：页面重建立即查询真实服务状态（不再等 10s 轮询纠正）
- **模型卡参数展示**：`体积 · ctx · 线程 · ubatch · KV`，改参数实时刷新
- **推荐参数卡片**：SoC 模板匹配 + 内存兜底，抽屉式折叠（默认收起）
- **状态胶囊精简**：无指示灯/无外框/无底色，开关颜色表达状态（运行绿/启动黄/错误红）
- **轮询性能**：checkPort 10s+页面守卫 / cliRefreshState 守卫 / 日志 500ms 仅可见时跑 / bmoe 1.2s→3s
- **深色对比度**：`--dim` 提亮至 WCAG AA（7.4:1）
- **引擎切换 loading**：600ms 禁用态防重复点击
- **测速表格淡入**：requestAnimationFrame 过渡

### 兼容性说明

- **MTP 测速**：MTP 引擎需要 MTP-GGUF 模型（Qwen3.5 MTP 权重）。用普通模型测 MTP 会显示"启动失败"——这是正确的探测结果
- **765G 类老设备**：MTP/NPU 不可用，测速请只勾 CPU；KV 量化对你无副作用
- **外部客户端模型名含路径**：上游未改（需 Java 层 `--alias`），仍建议客户端手填
