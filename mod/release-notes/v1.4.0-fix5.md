# PocketOrca-LLM v1.4.0 fix5 — 自选测速 + UI 精简 + 性能优化 + 全部既有修复

本包基于官方 **v1.4.0 release APK**（sha256 `14885aad…e5478`）以"手术式"修改制作，**未改动 dex 与推理逻辑**。

fix5 = fix4 全部内容 + 自选测速 + 状态胶囊 UI 精简 + 日志轮询性能优化。

> 安装：官方版需先卸载；fix1~fix4 用户可直接覆盖安装（同一签名）。

## 1. 自选测速（fix5 新增）

「引擎测速」卡片内新增 **NPU / GPU / CPU 勾选**：只测你勾选的引擎，不再强制三个全测。选择会被记住（下次打开保持）。未勾选任何引擎时点击会提示。

> ⚠ 低内存 / 老机型建议只勾 CPU：GPU 全量卸载在这些设备上可能造成系统压力（见下方"已知限制"）。

## 2. 状态胶囊 UI 精简（fix5）

- **移除指示灯**：状态已由开关轨道颜色表达（运行=绿 / 启动中=黄 / 错误=红 / 未运行=灰），左侧圆点冗余，已删除
- **移除外框与底色**：胶囊不再有描边和背景色，只保留"文字 + 开关"，视觉更干净
- **对齐修正**：中文文字与开关的垂直基线对齐（此前中文下沉导致视觉不齐）；开关滑块行程对称（此前右端偏移 2px）

## 3. 日志轮询性能优化（fix5）

日志页的 500ms 轮询此前在**所有页面**都运行（持续向 WebView 传输日志快照）。现改为**仅在日志页可见时轮询**，其它页面零开销。环形缓冲本身（2000 行内存）开销极小，不影响推理性能。

## 4. 防休眠说明（无需新增）

应用**已内置**防休眠机制，无需额外功能：
- 前台服务（FGS）+ **PARTIAL_WAKE_LOCK**：服务运行期间 CPU 不休眠，息屏不断服
- **WiFi 高性能锁**：息屏后局域网端点保持可达
- 首次启动引导申请**电池优化豁免**（"不受限"），避免厂商后台清理

若仍遇息屏断连，请确认系统设置中本应用为"允许后台活动/不受限"。

## 5. NPU(HTP) 启动崩溃修复（自 fix1）

v1.4.0 在 HTP arch > 79 机型（骁龙 8 Elite Gen 5 等）上 NPU 模式崩溃（`fastrpc_mmap failed` / exit 134）：新 DMA64 扩展映射与内置旧 `libcdsprpc.so` 不兼容。修复 = 强制 `opt_dma64 = 0`（`libggml-hexagon.so` 两处字节补丁）。修复后该 .so 的 sha256 与社区独立修复一致。

## 6. GPU(OpenCL) 旧驱动兼容（自 fix2/fix3/fix4）

v1.4.0 的 `libggml-opencl.so` 因 `BIND_NOW` 加载期强依赖三个新 OpenCL 符号/路径，旧 Adreno 驱动不支持 → GPU 引擎无法加载或闪退。共 10 处字节补丁：

| 问题 | 修复 |
|---|---|
| 缺 `clCreateBufferWithProperties`（CL 3.0） | 符号改名 + 调用点 nop（该调用属默认关闭的实验路径） |
| 缺 `clGetKernelSubGroupInfo`（CL 2.1） | 两调用点返回"查询失败"（走既有降级）+ 符号改名占位 |
| `flash_attn_repack` kernel 编译失败即 exit（旧驱动缺 3D image 写扩展） | fatal→0 + 4 处失败跳转 nop（该 kernel 组在本包中永不被使用） |

真机（骁龙 765G / Adreno 620 / Android 12）独立进程验证：GPU 引擎完整可用（模型 43/43 层卸载、服务器就绪、推理返回）。

## 7. 三引擎测速（自 fix1，fix5 增强为自选）

用**当前已选模型**依次启动勾选的引擎（与正常使用完全一致的路径），显示生成速度 t/s / 提示处理 t/s / 加载耗时，标出最快；完成后自动恢复原引擎。无 NPU / 驱动不支持的机型会显示"启动失败"——这是正确的探测结果。

## 已知限制

- **低内存 / 老 GPU 机型**（如骁龙 765G / 4~8GB）：GPU 全量卸载长时间运行可能超出系统承受力（实测曾触发系统保护性重启）。此类设备**请使用 CPU 引擎**，测速时只勾 CPU。
- 部分机型无可用 NPU（如骁龙 7 系旧平台），测速中 NPU 显示失败属正常。
